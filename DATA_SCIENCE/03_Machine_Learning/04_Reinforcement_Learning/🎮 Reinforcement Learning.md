# 🎮 Reinforcement Learning

An **agent** interacts with an **environment**, receives **rewards**, and learns a **policy** that maximizes long-term return. No labeled dataset — feedback comes from trial and error.

← Back to [[🤖 03 · Machine Learning|03 · Machine Learning]]

## Vocabulary
- **State** `s` — current situation
- **Action** `a` — what the agent can do
- **Reward** `r` — scalar feedback
- **Policy** `π(a|s)` — strategy mapping states to actions
- **Value** `V(s)` / `Q(s,a)` — expected future reward
