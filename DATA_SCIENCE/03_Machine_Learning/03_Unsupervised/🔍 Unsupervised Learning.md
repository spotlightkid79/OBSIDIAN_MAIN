# 🔍 Unsupervised Learning

Models trained on **unlabeled** data — no `y`, just `X`. Goal: discover hidden structure (groups, components, anomalies).

← Back to [[🤖 03 · Machine Learning|03 · Machine Learning]]

## Main tasks
- **Group similar points** → [[Clustering]] (KMeans, DBSCAN, Hierarchical)
- **Compress / visualize** → [[Dimensionality_Reduction]] (PCA, t-SNE, UMAP)
- *Anomaly detection, density estimation, association rules* — same family
