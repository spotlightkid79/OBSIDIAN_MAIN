## What it is
**Cross-Industry Standard Process for Data Mining** — the classic 6-phase reference framework still widely used.

1. Business Understanding → [[1 · Problem Definition]]
2. Data Understanding → [[2 · Data Collection]] + [[3 · Exploratory Data Analysis (EDA)]]
3. Data Preparation → [[4 · Preprocessing]]
4. Modeling → [[5 · Modeling]]
5. Evaluation → [[6 · Evaluation]]
6. Deployment → [[7 · Deployment & Monitoring]]

## Key idea
The arrows go backward too — you'll loop. EDA findings reshape the problem; eval failures send you back to features.
